Polter

Unseen, Unheard, Done. — pengaturan provider

Catatan jujur: tidak ada "login dengan akun ChatGPT / Claude / Gemini" ala aplikasi konsumen yang resmi untuk extension pihak ketiga. Yang dipakai adalah API key resmi masing-masing provider atau endpoint custom milikmu sendiri (misalnya 9Router). Semua key/token tersimpan lokal di browser ini saja (bukan encrypted vault — siapa pun yang memegang laptop bisa membacanya).

1. Pilih provider

Custom milik sendiri

Endpoint OpenAI-compatible apa pun. Mode potret area butuh model yang mendukung gambar (vision).

Muse (Meta) API resmi / bridge

Meta Model API (key dari dev.meta.ai) atau Muse Bridge milikmu sendiri. Tidak ada mode login Meta (lihat catatan di README).

OpenAI bayar

API key dari platform.openai.com.

Anthropic Claude bayar

API key dari console.anthropic.com.

AgentRouter gateway

Gateway agentrouter.org yang hanya menerima klien bergaya Claude Code / OpenCode — Polter meniru sidik jari kliennya (header + User-Agent).

4. Izin akses situs

Tab hantu Polter di tepi kiri layar hanya muncul di situs yang izin aksesnya sudah diberikan. Tanpa izin ini, yang tetap bisa dipakai adalah shortcut (Alt+Shift+S / Alt+Shift+D) dan klik ikon ekstensi, karena keduanya meminta akses sesaat. Klik tombol di bawah sekali untuk memberikan izin ke semua situs http/https (sesuai izin opsional yang memang dideklarasikan ekstensi ini), supaya tab dan deteksi otomatis muncul di platform kuis/LMS mana pun, termasuk yang soalnya di dalam iframe.
Status: ...
Di Chrome izin yang sama bisa diatur lewat ikon ekstensi > "This can read and change site data" > "On all sites". Di Firefox: about:addons > Polter > Permissions. Cabut kapan saja dari tempat yang sama.

5. Pintasan

Deteksi soal/formulir: klik tab hantu Polter di tepi kiri layar lalu pilih "Deteksi Soal di Layar", atau shortcut keyboard (default Alt+Shift+D).
Potret area: dari tab yang sama pilih "Ekstrak dari Foto", klik ikon Polter di toolbar, atau shortcut keyboard.
Buka Library: shortcut keyboard. Atur/ubah shortcut di chrome://extensions/shortcuts (Chrome memilih default bila konflik).
Tampilkan menu: shortcut keyboard (default Alt+Shift+M) — membuka menu awal Polter di halaman aktif, berguna terutama saat tab hantu disembunyikan (lihat bagian 6).

6. Tombol hantu

Saat disembunyikan, tab benar-benar hilang dari semua halaman. Panggil menu awal Polter kapan pun dengan shortcut Alt+Shift+M (tekan lagi atau Esc untuk menutup). Untuk menampilkan tab lagi, cukup pilih "Tampilkan" di sini — perubahan langsung berlaku di semua tab yang sedang terbuka, tanpa reload, dan tersimpan otomatis.
